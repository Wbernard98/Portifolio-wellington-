# Portfólio de Wellington Bernardes

Este é o portfólio pessoal de Wellington Bernardes, uma aplicação web simples e responsiva, que apresenta projetos realizados utilizando tecnologias como **HTML**, **CSS**, **JavaScript**, **TypeScript**, e integração com APIs. O objetivo do portfólio é demonstrar habilidades técnicas e criativas, com links diretos para os repositórios dos projetos.

---

## Funcionalidades

- Exibição de **projetos** realizados, com links para os repositórios do GitHub.
- Imagens de **pré-visualização** e imagens de hover para os projetos.
- Seção de apresentação com uma **mensagem de boas-vindas** personalizada.
- **Responsividade**: funciona bem em dispositivos móveis e desktops.
- Links para as redes sociais do desenvolvedor (LinkedIn, GitHub, Instagram).

---

## Tecnologias Utilizadas

- **HTML**: Estruturação básica da página e conteúdo.
- **CSS**: Estilização do layout e design responsivo.
- **JavaScript/TypeScript**: Lógica de interação e manipulação de dados (para alguns projetos).
- **API OpenWeatherMap**: Utilizada no projeto de condições climáticas.
- **Google Fonts**: Fonte personalizada (`Poppins`).

---

## Como Usar

### 1. Clone o Repositório

Clone este repositório para sua máquina local:

```bash
git clone https://github.com/Wbernard98/portifolio-wellington.git
```
2. Abra o Projeto
Abra o arquivo index.html em seu navegador para visualizar o portfólio.
